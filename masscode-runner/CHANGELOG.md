# 更新记录

## v2.3.0 — 2026-09-14

- PDF 阅读内核切换为本地打包的 Mozilla PDF.js 官方 Viewer，保留 CodeScope 的摘录、高亮、笔记、AI 重点、目录和引用回链，不再维护整本 PDF 的自制画布布局。
- 新增连续滚动、单页、双页、封面双页、20%–400% 自由缩放、适合宽度、适合整页、实际大小、旋转与手型拖动；视图模式、缩放、旋转和工具状态按文档记忆。
- 大 PDF 改为可视区页面渲染，279 页实测连续模式仅保留当前附近画布；缩略图也使用 IntersectionObserver 按需生成，避免一次渲染整本文件。
- AI 重点定位不再为了查找原句渲染全部页面，先基于服务端页级文本定位候选页，再只渲染目标页并生成高亮。
- 阅读工具栏新增 ONLYOFFICE PDF Editor 入口，复用现有 Document Server 连接、JWT 与安全回调，编辑结果自动回写阅读库，并在隐藏目录保留最近 5 份 PDF 备份。
- 修正官方 Viewer 的 CSS 缩放单位与旧标注坐标系差异，使既有高亮、摘录标记和点击命中在不同缩放及页面模式下保持对齐。

## v1.2.0 — 2026-09-05

### 新增

- 阅读文库升级为“阅读项目 → 多类型片段”结构，一篇论文可集中管理 PDF 原版、已有中文版、双语版、Markdown 笔记与代码片段。

- Markdown 与代码片段可拖入双栏工作区直接编辑并自动保存，项目及片段均支持独立重命名和删除。
- PDF 阅读栏新增“可选文本”视图，解决浏览器内置 PDF 插件选区无法被外层读取的问题；选段翻译与摘录会自动引导切换到可读取的同页文本。
- 阅读片段侧栏新增横向拖拽分隔条，支持在桌面布局中自由调整宽度并记忆设置。

- 阅读库补齐多级文件夹以及项目说明、标签元数据；文件夹可新建、嵌套、重命名和删除，旧版顶层阅读项目无需迁移即可继续使用。

- “＋片段”改为统一新建窗口，可在同一阅读项目中导入 PDF，或创建 Markdown、LaTeX、C/C++、头文件、Python、JavaScript、TypeScript 与纯文本片段。
- 修复 PDF 视图切换：项目中已有中文版或双语版 PDF 时直接切换到对应文件，并在下拉项中明确显示“中文 PDF / 双语 PDF”；仅在缺少实体译本时回退到 AI 页级译文，同时恢复每个文档上次使用的视图。
- 新增英文 PDF 的 AI 选段、单页和全文翻译；译文按页持久化，不修改原始 PDF。
