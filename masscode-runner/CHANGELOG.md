# 更新记录

## v2.1.0 — 2026-09-14

### Web 与桌面双模式

- 新增 Electron 桌面入口，Web 端与桌面端共用服务 API、工作台界面和 Vault 数据格式。
- 桌面端新增原生菜单、单实例运行、Vault 选择与持久化、独立 Utility Process 服务以及安全 preload 桥接。
- 桌面安装包内置 Electron、Node.js 和 npm 运行依赖，安装后可直接启动；程序、缓存与 Vault 数据分离，升级不会覆盖用户资料。

### 跨平台发布

- 新增 Electron Forge 打包配置，支持 macOS DMG/ZIP、Windows Squirrel 安装包以及 Linux DEB/RPM/ZIP。
- 新增 GitHub Actions 桌面发布流水线，推送版本标签后自动构建三端安装包并统一上传到 GitHub Release。
- 接入 GitHub Release 更新源；Windows 和已签名、公证的 macOS 版本可检查并安装后续更新，Linux 通过 Release 或系统软件包更新。

### 安全与质量

- Electron 渲染进程启用上下文隔离、沙箱并关闭 Node.js 注入，外部链接交由系统浏览器处理。
- Web/桌面接口新增运行模式和原生能力契约，并补充 CSP、桌面入口、构建配置及真实浏览器回归测试。
- 排除 SSH 的可选原生 CPU 加速模块，避免桌面安装包要求用户额外配置编译工具链。

## v2.0.0 — 2026-09-14

### 工作台统一

- 统一项目、Office、阅读、绘图与 Git 的侧栏视觉体系，包括标题栏、图标、计数徽标、操作按钮、树层级、悬停和选中状态，并补齐窄侧栏响应式布局。
- 完成深海蓝、石墨灰、午夜紫、森林绿和日光白主题的语义化表面适配，减少模块间硬编码颜色和尺寸差异。
- 品牌版本由服务端版本接口驱动，避免界面、包元数据和发布标签显示不一致。

### 环境与跨平台

- 新增 `preflight.js`，统一检查 Node.js 18+、端口、监听地址、Vault/临时目录权限和全部运行依赖；支持文本与 JSON 输出。
- macOS、Windows、Linux/WSL 启动脚本接入统一预检，局域网地址仅在显式开启外部监听时显示，默认继续仅监听本机。
- 环境面板新增“运行基础 / 浏览器能力 / 项目工具链”分组，覆盖应用数据目录、依赖完整性、WebAssembly、Worker、IndexedDB、Pointer Events、ResizeObserver 与 ONLYOFFICE 状态。

### 一体化能力

- 代码阅读与编辑整合 Monaco、多栏、LSP、定义/引用/调用关系、工程构建测试调试、Git Diff、远程开发与本地时间线。
- Markdown 完成源码、分栏、实时原位编辑与阅读模式，并整合区块操作、原生撤销、代码/PDF 引用及双向定位。
- PDF 阅读项目支持原文/译本/笔记/代码片段一一对应；Draw.io、Excalidraw、XMind 与 Office 作为一级工作区统一管理。
- XMind 导图补齐官方原貌查看、直接编辑、缩放平移、节点拖拽、父子关系迁移、自由节点、多布局和主题；Office 支持 ONLYOFFICE 完整编辑及离线兼容模式。

### 质量

- 扩展服务端静态回归与真实 Chromium 浏览器回归，覆盖版本契约、环境就绪数据、统一侧栏尺寸和浏览器能力呈现。
- 重写项目首页和版本说明，明确数据位置、降级策略、安全边界、跨平台启动方法及验证命令。

## v1.2.0 — 2026-09-05

### 新增

- 阅读文库升级为“阅读项目 → 多类型片段”结构，一篇论文可集中管理 PDF 原版、已有中文版、双语版、Markdown 笔记与代码片段。
- 自动识别文件名中的“中文 / 双语”等版本角色；打开项目时优先把原版和已有中文 PDF 并排显示，不再误用尚未生成的 AI 页级译文。
- Markdown 与代码片段可拖入双栏工作区直接编辑并自动保存，项目及片段均支持独立重命名和删除。
- PDF 阅读栏新增“可选文本”视图，解决浏览器内置 PDF 插件选区无法被外层读取的问题；选段翻译与摘录会自动引导切换到可读取的同页文本。
- 阅读片段侧栏新增横向拖拽分隔条，支持在桌面布局中自由调整宽度并记忆设置。
- 阅读项目改为与代码工程一致的“项目 + 顶部片段标签”交互：左侧只列项目，PDF、译本、Markdown 和代码片段在中间统一选择、重命名、删除，并可拖入左右栏自由组合；右侧原“阅读片段”更名为“摘录笔记”以消除概念混淆。
- 阅读库补齐多级文件夹以及项目说明、标签元数据；文件夹可新建、嵌套、重命名和删除，旧版顶层阅读项目无需迁移即可继续使用。
- 阅读库文件夹与项目支持拖拽改变层级；阅读工作区移除固定单栏/双栏按钮，默认单栏，拖动顶部片段到右侧即可自动生成第二栏，关闭栏位后自动回收布局。
- “＋片段”改为统一新建窗口，可在同一阅读项目中导入 PDF，或创建 Markdown、LaTeX、C/C++、头文件、Python、JavaScript、TypeScript 与纯文本片段。
- 修复 PDF 视图切换：项目中已有中文版或双语版 PDF 时直接切换到对应文件，并在下拉项中明确显示“中文 PDF / 双语 PDF”；仅在缺少实体译本时回退到 AI 页级译文，同时恢复每个文档上次使用的视图。
- 新增英文 PDF 的 AI 选段、单页和全文翻译；译文按页持久化，不修改原始 PDF。
- 新增论文与开发文档片段管理，摘录自动关联页码，可保存译文和个人笔记并快速定位。
- 新增全部片段全文搜索，支持大小写匹配、正则表达式、结果高亮和跨文件定位。
- 新增 `Ctrl/⌘+P` 快速打开文件，并与 AI、符号和搜索记录统一到搜索中心。
- 新增代码位置前进/后退导航、`Alt+F12` 定义预览和 `Alt+O` 同名头文件/源文件切换。
- 新增 VS Code 式 `Ctrl/⌘+单击` 跳转定义，覆盖函数、类型、宏、变量及多栏编辑器，并在按住修饰键悬停时提示目标。
- 新增 VS Code 式符号悬停卡片，停留约 550 毫秒后显示函数、类型、宏或变量的签名、定义位置和源码片段；卡片支持鼠标移入、横向/纵向滚动和长定义浏览。
- 新增通用 LSP 适配层，首批支持 clangd、Pyright、TypeScript Language Server 和 gopls；语言服务器不可用时自动回退内置符号索引。
- 新增代码面包屑、当前函数 Sticky Scope 和语言服务器问题入口，滚动或移动光标时同步显示所在文件、类型、函数及签名。
- 新增真实 Chrome/Chromium 浏览器回归测试，覆盖代码面包屑、悬停卡片交互、内部滚动、LSP 状态和首屏按需加载。

### 优化

- 导航历史覆盖左侧选中、文件标签切换、多栏主编辑器切换和搜索结果跳转。
- 定义预览沿用当前主题的语法高亮，可继续打开完整定义，减少阅读时上下文丢失。
- 关系图曲线末端改为更小的实心三角箭头，提升方向辨识度并减少视觉重量。
- 代码补全改为仅按 `Ctrl/⌘+Space` 手动触发，普通输入和移动光标不再弹出遮挡代码。
- 本地时间线改为按连续编辑会话合并，两分钟内多次自动保存只保留一个会话起点，并折叠已有的相邻冗余记录。
- 版本接口补充代码阅读能力标识，自动化测试改为动态统计通过项。
- 思维导图库改为首次打开导图时按需加载，减少普通代码阅读场景的首屏脚本体积。

## v1.0.0 — 2026-09-04

码境 CodeScope 首个正式版本。

### 核心能力

- 支持代码片段、Markdown、LaTeX 工程与绘图文件的统一管理和编辑。
- 提供代码大纲、符号定位、引用检索、调用关系图和树形关系浏览。
- 支持多文件 C/C++ 等代码的运行、检查、格式化及交互式终端。
- 提供 Markdown 实时预览、思维导图及 PNG/SVG 导出。
- 提供 LaTeX 工程目录、资源管理、实时编译和 PDF 预览。
- 集成环境检测、一键部署、CPU/内存/磁盘状态监测。
- 集成 SSH 交互终端与 VNC 远程桌面，支持输入法、窗口适配和网络延迟显示。

### 平台与兼容

- 支持 macOS、Linux/WSL 和 Windows 启动与环境配置。
- 新增 `CODESCOPE_HOST`、`CODESCOPE_PORT`、`CODESCOPE_VAULT` 配置。
- 继续兼容既有 `MASSCODE_*` 环境变量及 massCode Markdown Vault。
