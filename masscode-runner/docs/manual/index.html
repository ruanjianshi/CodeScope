快速开始

macOS 图标启动

  1. 双击桌面 CodeScope 图标启动器检查 Node、Vault、依赖、ONLYOFFICE 与 DSH。
  2. 等待浏览器打开默认地址为 http://127.0.0.1:4877。
  3. 检查 Vault顶栏路径应以 markdown-vault 结尾，左侧项目数量应正常。
  4. 开始工作选择左侧内容，或使用欢迎页和顶栏入口。

命令行启动

cd "/path/to/massCode/masscode-runner"
npm install
npm start

Node.js 需要 18 或更高版本。默认只监听本机；可信局域网访问需显式设置 CODESCOPE_HOST=0.0.0.0。

首次检查

  • Vault 路径正确。
  • 项目、阅读、Office 与绘图数据正常。
  • 环境面板运行基础可用。
  • 打开代码后 Monaco 编辑器出现。
  • 需要 Office 时容器状态为健康。

数据与 Vault

CodeScope 数据不是锁在私有数据库中，而是保存为可直接查看与备份的文件。

markdown-vault/
├── code/       # 代码、多文件工程、LaTeX
├── notes/      # Markdown 笔记
├── readings/   # PDF、网页、Office 阅读资料与标注
├── office/     # ONLYOFFICE 文档
├── drawings/   # Draw.io、Excalidraw、XMind
├── libraries/  # 依赖资源
└── .codescope/ # 工作台配置与元数据
文件看似全部消失时通常是服务指向了错误 Vault。先看顶栏路径；正确目录应为 .../massCode/markdown-vault。切回后文件立即恢复，不要在空目录重复新建。

备份原则

  • 文本与源码使用 Git。
  • 完整 Vault 使用 iCloud 或其他云盘。
  • 重要 PDF、Office 与媒体另做离线备份。
  • 时间线用于误操作恢复，不替代正式备份。

编辑态与只读态

  • 工具栏 📖 只读：默认是编辑态（按钮不高亮），点一下进只读并高亮，再点一下回编辑；切到只读会先把当前修改落盘。Markdown 与 HTML 片段不显示这个按钮：Markdown 在代码工作区统一用区块编辑，HTML 用工具栏右侧的“源码 / 分栏 / 实时 / 阅读”切换器。
  • 只读态用静态高亮层渲染（Monaco 面板隐藏），可以正常滚动、显示行号，字号与编辑态完全一致。
  • 折叠只在只读态真正生效：编辑区是原生文本域，点折叠箭头会提示先切到只读。
  • 开自动换行（Alt+Z）时行号仍然显示：没有超长行时完全对齐；只有出现被折行的超长行之后，它后面的行号才会偏移。（多栏编辑时这条修复还没覆盖到：辅助栏开自动换行后行号仍会整片隐藏。）

代码图谱与逻辑图

代码区工具栏右侧有三个紧挨着的图标按钮（鼠标悬停看提示）：🕸 图谱看整篇文档的片段、函数与依赖关系，⇉ 逻辑图看当前函数内部的控制流，🧩 积木进图形化编程。它们都是开关：再点一下关闭。三个按钮只在当前文档含代码片段时出现，纯 Markdown / LaTeX / 纯文本（plain_text）文档下自动隐藏。

🕸 代码图谱

力导向网络图：片段是琥珀色大圆、函数是蓝色中圆，可拖动节点、滚轮缩放；边按类型上色 —— 调用是实线强调色，include 是虚线灰并带 include 标签。顶部有图例；点节点跳源码，双击函数节点用积木打开。

⇉ 逻辑图

if / else / for / while / do…while / switch 的真实分支与循环结构；节点上的 L 行号可点击跳回源码。

操作

  • 图谱栏：⟳ 刷新、⤢ 全屏放大、⧉ 复制 Mermaid 源码、✕ 关闭。
  • 逻辑图栏：⚡ AI 解读、✎ 编辑、↩ 生成代码、⟳ 刷新、⤢ 放大、🧩 用积木打开、⧉ Mermaid、✕ 关闭。
  • 默认显示结构控制流图（即时、不消耗 AI 配额）；点「⚡ AI 解读」才走模型（解读过的函数缓存在当前页面里，刷新即失效），再点一下在“解读 / 结构图”之间切换。
  • 点「✎ 编辑」进入图形化编辑：双击改内容、＋插入、✕ 删除、↑↓ 调序；进入编辑后才能点「↩ 生成代码」。
  • 代码区与右栏之间的分隔条可拖动，宽度自动记忆。
生成代码不会写回文件逻辑图生成的结果只出现在图下方的代码框，配一个「⧉ 复制代码」按钮，需要自己到编辑器里选中原文粘贴。

已知限制

  • 控制流解析面向 C/C++ 的语句结构，其它语言不保证正确。
  • 逻辑图的节点文字是截断后的显示文本（超过 42 字符以 … 结尾），只用于显示，不参与生成代码；代码图谱的节点标签不截断，用完整文件名 / 函数名。
  • 「AI 解读」需要可用的 AI 连接，本手册未验证该路径；解读结果只缓存在当前页面内存里，刷新页面后要重新解读。

图形化编程（积木）

参考米思奇 Mixly 的积木式编程，重点却是双向：核心是「把已有函数拆成积木」（代码 → 积木），拖拽改完再「生成代码」（积木 → 代码）。积木由内置的 Blockly 渲染（形状即类型、颜色即分类），积木定义全部由 CodeScope 自己实现。

打开与同步

  1. 把光标放到一个函数里积木栏认的是“光标所在函数”，不是屏幕中间那个函数；光标不在任何函数里时会提示先放光标。
  2. 点工具栏 🧩 积木主区域右侧展开三栏：左积木库、中工作区、右生成代码。两条分隔条都能拖，宽度各自记忆。
  3. 点「⇄ 从代码同步」把当前函数解析成 CFG，再按嵌套关系拆成积木。光标换函数、换片段、换文档时会自动重新同步（切走前先把你的改动落盘）。
  4. 拖积木改逻辑右侧代码面板实时刷新，并按关键字 / 类型 / 字符串 / 数字 / 函数名 / 注释 / 预处理上色（CodeScope 自带的小高亮器，不走 Monaco）。
  5. 点「↩ 生成代码」输出完整函数（含签名），随后自检：把生成的代码再送解析器，比对语句数是否与原函数一致。

悬停看签名

把鼠标停在“调用”积木上，会显示这个函数在当前文档所有片段里的真实签名（像 IDE 的参数提示）；宏也能查，找不到会明说“文档里没找到它的定义”。提示是纯文本，超过 90 字符会截断；下拉里换了函数名，提示跟着变。其它积木也各有一条自己的提示，说明每个槽该填什么（例如“容器声明”会提示先选类型再填变量名，“自动加锁”会提示别手动 lock/unlock）。

改动存在哪

  • 按「文档 # 片段 # 函数」缓存进浏览器 localStorage 的 mc-bp-edits；改动后防抖 800ms 自动保存，最多保留 40 份，超了丢最旧的。
  • 切走再切回来优先恢复你的编辑，统计栏显示“已恢复上次的编辑”；点「↺ 还原为代码」显式丢弃。
  • 没编辑过的函数不缓存；localStorage 配额满时静默跳过，不影响使用。
  • 积木状态不写入 Vault：换浏览器或清缓存后回到按源码生成的版本。

已知限制

  • 只能表达 CFG 能解析的构造；宏、位域、内联汇编等请用「原样代码」积木兜底。
  • 自检提示“解析出 N 条语句，原函数 M 条”时说明有构造表达不了 —— 别直接覆盖原文。
  • 生成的代码会重排缩进、给单行 if 补花括号：语义相同、格式不同。
  • 生成的表达式不会用图上那种截断过的显示文本：CFG 节点的 label 一旦带 … 就会回源码取原文，所以不会生成 x = (a != NULL… 这种残句。
  • 调用 / 变量 / 类型下拉来自当前文档的符号索引（函数、变量、宏、struct、typedef、enum），每一类都只取前若干个。
回归测试node tests/blockly-validate.js 校验全部积木定义（占位符数量 + 每个都真的能创建）；node tests/blockly-roundtrip.js "/绝对路径/文档.md" 遍历文档里每个函数，逐字比对“原文 ↔ 积木生成的代码”。

Markdown 与笔记

Markdown 提供源码、分栏、区块编辑与阅读模式。区块编辑支持标题、列表、任务、引用、代码、表格、公式和图片。

  • 源码：精确控制原文。
  • 分栏：左源码、右预览，按源码行同步滚动。
  • 区块：输入 / 打开菜单，拖六点手柄重排。
  • 阅读：隐藏编辑控件，适合长文。
定位左侧大纲跟随章节；代码、PDF 和笔记内部链接支持反向引用。

统一阅读模块

一个阅读项目可组合 PDF、Word、表格、演示文稿、网页、Markdown、LaTeX 与代码。资料标签拖到右侧即可双栏阅读。

PDF

  • 20%–400% 缩放、适宽、整页和实际大小。
  • 连续、单页、双页、封面双页。
  • 全文查找、目录、缩略图、旋转、手型与专注模式。
  • 摘录、高亮、笔记，并可定位回原页。
  • 可视区域懒渲染，适合数百页文件。

Word / Excel / PPT

阅读模式本地解析：Word 保留分页结构，表格支持工作表，演示文稿逐页查看。需要高保真编辑时进入 Office 工作区。

网页

网页资料会提取正文，文档站保留完整目录、章节历史、相邻页预取、40%–240% 整页缩放、摘录与原文定位。

网站限制禁止 iframe 或复杂登录的网站，应使用“原网页”或学习工作台；CodeScope 不绕过网站安全策略。

Markdown 知识库

顶栏“知识库”用于管理和阅读长期积累的 Markdown 文档。CodeScope 使用 VitePress 把文件夹结构自动生成类似 GitBook 的完整文档站。

层级目录

文件夹就是分类，可创建任意层级。

全文搜索

浏览器本地完成中文模糊检索。

大图友好

图片独立保存、按需加载并带缓存。

创建与写作

  1. 打开知识库中心点击顶栏“知识库”，查看页数、图片容量和构建状态。
  2. 创建分类或文档输入如 嵌入式 Linux/设备驱动.md，多级目录会自动建立。
  3. 编辑 Markdown新文档会在阅读模块打开，可使用源码或区块编辑器。
  4. 自动生成保存后 CodeScope 防抖重建站点；状态变为“知识库已更新”后即可阅读。

图片与大容量内容

在知识库中心选择图片分类并导入 PNG、JPG、GIF 或 WebP。图片存放在 readings/知识库/public/images/，界面会复制 Markdown 图片语法。站点启用懒加载，页面不会一次解码全部图片。

阅读与定位

  • 左侧是按文件夹生成的分类树，右侧是当前页面二至四级标题大纲。
  • 顶部搜索支持标题加权、前缀和模糊匹配，所有索引均留在本机。
  • 标题具有稳定锚点，可复制当前链接直接定位；支持上一篇、下一篇和返回顶部。
  • 源文件位于 Vault，站点缓存位于 CodeScope 应用数据目录；缓存损坏时点击“重新生成”即可恢复。

地址与命令行重建

  • 站点地址 http://127.0.0.1:4877/knowledge/；顶栏知识库的“内嵌阅读 / 分栏学习 / 外部打开”都用这个地址。
  • 命令行重建：npm run build:knowledge，成功时打印“知识库已生成：N 篇文档 → 生成目录”。
  • CodeScope 服务启动时会自动接管生成，保存 Markdown 后防抖重建；构建有超时看门狗，卡住时状态不会永远停在“正在生成”。
  • 本机实测引擎为 VitePress 1.6.4；源目录 readings/知识库，生成结果在应用数据目录 <dataRoot>/knowledge/site（macOS：~/Library/Application Support/CodeScope/knowledge/site）。
  • .vitepress/ 里的配置是生成出来的唯一入口，不要手改 —— 要改行为就改生成器。
推荐结构知识库/领域/专题/文档.md。分类保持稳定、单篇围绕一个主题，图片按项目或专题归档。

学习工作台

把视频、网页、代码、PDF 和笔记放进可拖拽窗格。常用网址支持搜索、分类、新增与移动。

布局

  • 学习布局：左视频，右侧代码与笔记上下排列。
  • 双栏：视频｜代码或视频｜笔记。
  • 四宫格：视频、资料、代码、笔记。
  • 自由布局：拖动标签和边界任意重组。

B站学习

  1. 打开完整 B站登录、搜索并选择视频。
  2. 载入播放器复制视频地址后放入视频窗格。
  3. 记录时间点在关键位置插入可回跳节点。
  4. 记录视频帧把当前播放器画面加入学习记录。
  5. 同步实践右侧改代码并记录笔记。

代码向导

在代码里按 ⌘I（Windows / Linux 为 Ctrl+I）唤出一个浮在页面上的小窗口，一边写代码一边查。它不挡点击、可以拖到边上、可以折成一条，位置会被记住。

查手册
这个词怎么用找方案
这件事怎么做拆逻辑
这段在干什么

查手册

  1. 把光标放到要查的词上打开时会自动带上它。
  2. 看「定义 / 增删改查 / 例子」来自速查手册，不是泛泛而谈。
  3. 看「常用成员」与「容易踩的坑」两边一起给出，少踩一次就省半小时。

找方案

  1. 先用大白话说你要干什么例如「我想统计一段文本里每个词出现了几次」。
  2. 先搜本地，再让 AI 按你的上下文想给出「用哪个包 / 哪个函数 + 例子」。
  3. 用「插到光标处」直接把示例代码写进编辑器。

拆逻辑

  1. 光标放进函数体它会先出控制流图（本地解析，毫秒级），再让 AI 把它讲成人话。
  2. 看思维导图每一步在干什么、哪里会分叉，都不出现代码原文。
  3. 点「跳过去」能定位到源码行。

查阅历史

标题栏的 🕘 是「我查过什么」。每一条都记着是哪个页签查的、查询词，以及「刚刚 / N 分钟前」这种人话时间。

点一条就是秒开结果跟着历史一起存下来了，回看不用再等 AI 重算一遍。结果太大的（比如很长的思维导图）只保留最近若干条，那些条目点开会重查一次。

存到知识库

  1. 历史每行一个 📥，结果区也有一个「存到知识库」刚查完就能存。
  2. 选分类 / 项目下拉里是知识库里现有的；要新的就选「＋ 新建分类…」「＋ 新建项目…」，那一格会变成输入框。
  3. 看「会存到」那一行实时显示完整路径，存之前就知道落在哪。
  4. 看正文预览存的是查到的内容（手册的定义/增删改查/例子、方案的思路/步骤/示例、拆解的输入输出/步骤/坑），不是空模板。
为什么要分类 / 项目两级这是知识库自己的目录结构（知识库/分类/项目/文档.md）。照它的结构来，知识库里就只有一套目录，不会看着乱。

个人管理面板

顶栏的个人管理面板是一个本地优先的个人管理系统：今日、备忘录、日记、书签、阅读、邮箱、工作流、趋势。数据默认只存本机。

今日

  • 一条格言（同一天内稳定，不会每次重绘都换）、心情、天气。
  • 待办、连续记录天数、今日日记一眼可见。

备忘录

  • 文件夹、标签、智能项（未完成 / 今天 / 已归档）三套视图。
  • 点文件夹就是「我要看这个文件夹」会顺带切回文件夹视图。
  • ⌘Z 撤销 / ⌘⇧Z 重做；⌘N 新建；⌘F 搜索。
  • 支持拖拽改归属、右键菜单、格式菜单（Aa）。

书签（常用网址）

  • 点一下直接打开（按记下来的方式：B站首页开可登录的一方窗口，别的走面板内阅读）。
  • 右键改打开方式（内部 / 外部），选一次就记住；⌘ / Ctrl + 点击 = 临时用系统浏览器打开。

邮箱

  • 真的能收信、读信、管理邮件（IMAP / SMTP，凭据只存本机）。
  • 新建 / 删除分类会真的在邮箱服务器上操作；IMAP 只允许删空的文件夹，服务器拒绝是好事。
  • 可以把邮件拖到左栏文件夹里归档。

工作流

  1. 「✨ 示例」一键搭一张真能跑的图（B站热门 → AI 挑 5 条 → 写进备忘录）。
  2. 连线、分支、循环参考 n8n 的设计；每个节点都能看到「输出什么」供下游引用。
  3. 跑完看运行历史每一步的结果、耗时、失败原因都在。

趋势

把一段时间里的记录聚合成日报，用 AI 挑出变化与值得注意的地方。

数据在哪面板数据存在应用数据目录（macOS：~/Library/Application Support/CodeScope/），Vault 里的内容仍然是普通文件，可以直接查看与备份。

环境检测

顶栏「环境」按钮打开环境检测侧栏，回答两件事：这台机器现在缺什么，以及缺了能不能当场修好。顶部三张卡片是 运行就绪 / 运行问题 / 外部服务未连接；下面两张服务卡结构一致 —— 状态点 + 名称 + 状态标签，一行元信息（悬停看完整内容），再一行操作按钮。

  • DeepSeek Harness：打开 在内嵌工作区打开、启动 拉起进程、关闭 停掉进程（下次启动 CodeScope 会重新拉起）、重启 换一个新进程。四个按钮会按当前状态自动灰掉，例如运行中时「启动」不可点、停止后「打开」与「关闭」不可点。
  • CodeScope 本地服务：显示 PID / 端口 / 已运行时长 / Node 版本，第二行是日志路径；重启 让服务换一个新进程接管端口（改过 server.js 或 lib/*.js 后用它，约 3–10 秒不可用）。
  • 再往下依次是基本信息键值网格（版本 / Node / 平台 / 项目语言 / Vault 路径）、云同步（Tailscale 组网 + Syncthing 数据面 + restic 快照，含设备列表与 GitHub 状态）、项目工具、运行基础与浏览器能力逐项检测；「开发与集成扩展」默认折叠。

远程同步到 VPS

  1. 填目标机host / user / port / 私钥文件 / remoteDir / projectName / 传输方式，以及 includeVault、includeNodeModules、remoteInstall、部署后重启命令、deleteExtraneous 开关。
  2. 先点“预演同步（不写远端）”用 rsync -n 列出会传什么、会删什么，这一步不写远端任何文件。
  3. 再点“同步到 VPS”真正把仓库内容送过去。
  4. “部署到 VPS”= 同步 + 远端 npm install --omit=dev + 白名单重启。
  5. “自检（只探测）”确认免密 SSH 通不通、远端有没有 rsync、目标目录可写性与磁盘余量。
  • 配置存在应用数据目录的 vps-sync.json（macOS：~/Library/Application Support/CodeScope/vps-sync.json）。
  • 传输方式自动挑：rsync 首选 → tar → scp 兜底；因为 rsync 的 -e 参数不支持引号，私钥路径含空格时会退回 tar / scp。
  • 四个动作都进任务控制台：有实时输出、可以取消。
安全边界默认不加 --delete，只有显式打开 deleteExtraneous 才加；即使打开，删除范围也只在 <remoteDir>/<projectName> 之内。默认排除 .git、node_modules、*.log、.DS_Store、__pycache__、.cache；markdown-vault 默认会一起同步（includeVault 默认开），不想把笔记库推上去就在面板里关掉它。远端重启命令只接受 systemctl / pm2 / docker compose 的 restart 前缀。

工程能力

LaTeX

“＋TeX”生成 main.tex 与 data/figures/fonts；左源码、右 PDF，防抖编译并处理交叉引用。

DeepSeek Harness

CodeScope 自动托管 DSH，默认监听 127.0.0.1:3080。顶栏 Harness 在主区域打开；环境面板可检查、查看日志和重启。

工程面板与 Git

工程面板集中展示任务、测试、调试、编译数据库和健康报告。Git 面板提供 Diff、提交、拉取与推送；危险回退要求短 hash 二次确认。

编辑工作台（内嵌 VS Code）

顶栏“编辑工作台”在 CodeScope 内打开浏览器版 VS Code（code-server）：可打开本机任意文件夹，带终端与扩展市场（Open VSX）。它只绑 127.0.0.1（默认端口 4899，被占时自动往后找），对外经 CodeScope 的同源代理转发 HTTP 与 WebSocket。首次使用需装一次：

mkdir -p ~/.codescope
cd ~/.codescope
npm install code-server

它不进 package.json 依赖：其 postinstall 会用 Electron 版去 rebuild VS Code 原生模块，必然失败。

SSH / VNC

远程面板支持 SSH 终端、远程文件、流式传输和 noVNC。监听 0.0.0.0 时同网段设备可能访问终端和文件接口，只应在可信网络使用。

搜索、引用与 AI

  • 快速打开：搜索代码、阅读、Office 与绘图。
  • 全文搜索：代码、Markdown、LaTeX 与 PDF 摘录，支持正则。
  • 内部链接：复制当前内容链接，建立跨资料引用。
  • 反向链接：查看哪些内容引用当前项目。
  • AI 搜索：结合实时网络资料与当前工程符号。
