代码阅读、编辑、运行、工程资料、视频学习、Office、绘图和远程开发的一体化工作台。本手册既是功能索引，也是一套可直接照着操作的演示指南。

快速开始

macOS 图标启动

  1. 双击桌面 CodeScope 图标启动器检查 Node、Vault、依赖、ONLYOFFICE 与 DSH。
  2. 等待浏览器打开默认地址为 http://127.0.0.1:4877。
  3. 检查 Vault顶栏路径应以 markdown-vault 结尾，左侧项目数量应正常。
  4. 开始工作选择左侧内容，或使用欢迎页和顶栏入口。

命令行启动

cd "/path/to/massCode/masscode-runner"
npm install
npm start

Node.js 需要 18 或更高版本。默认只监听本机；可信局域网访问需显式设置 CODESCOPE_HOST=0.0.0.0。

首次检查

  • Vault 路径正确。
  • 项目、阅读、Office 与绘图数据正常。
  • 环境面板运行基础可用。
  • 打开代码后 Monaco 编辑器出现。
  • 需要 Office 时容器状态为健康。

数据与 Vault

CodeScope 数据不是锁在私有数据库中，而是保存为可直接查看与备份的文件。

markdown-vault/
├── code/       # 代码、多文件工程、LaTeX
├── notes/      # Markdown 笔记
├── readings/   # PDF、网页、Office 阅读资料与标注
├── office/     # ONLYOFFICE 文档
├── drawings/   # Draw.io、Excalidraw、XMind
├── libraries/  # 依赖资源
└── .codescope/ # 工作台配置与元数据
文件看似全部消失时通常是服务指向了错误 Vault。先看顶栏路径；正确目录应为 .../massCode/markdown-vault。切回后文件立即恢复，不要在空目录重复新建。

备份原则

  • 文本与源码使用 Git。
  • 完整 Vault 使用 iCloud 或其他云盘。
  • 重要 PDF、Office 与媒体另做离线备份。
  • 时间线用于误操作恢复，不替代正式备份。

代码工作区

Monaco 编辑器

多光标、折叠、补全、查找替换、缩放与格式化。

语言服务 LSP

定义、引用、重命名、诊断、签名和快速修复。

运行与测试

stdin、stdout、退出码、耗时和 Case 对比。

创建与组织

  1. “＋文件”创建单文件片段，“＋TeX”创建 LaTeX 工程。
  2. C/C++ 多文件可把头文件、源文件与测试放在同一片段。
  3. 文件夹支持多级嵌套，项目和文件可拖拽移动。
  4. 标签和说明用于搜索、筛选与知识归档。

阅读定位

  • 右侧大纲按类型、函数、宏和全局变量分组。
  • F12 定义；Shift+F12 引用；Alt+F12 固定预览。
  • Ctrl/⌘+P 快速打开；Ctrl/⌘+Shift+F 全文搜索。
  • Alt+O 在同名头文件与源文件间切换。

Markdown 与笔记

Markdown 提供源码、分栏、区块编辑与阅读模式。区块编辑支持标题、列表、任务、引用、代码、表格、公式和图片。

  • 源码：精确控制原文。
  • 分栏：左源码、右预览，按源码行同步滚动。
  • 区块：输入 / 打开菜单，拖六点手柄重排。
  • 阅读：隐藏编辑控件，适合长文。
定位左侧大纲跟随章节；代码、PDF 和笔记内部链接支持反向引用。

统一阅读模块

一个阅读项目可组合 PDF、Word、表格、演示文稿、网页、Markdown、LaTeX 与代码。资料标签拖到右侧即可双栏阅读。

PDF

  • 20%–400% 缩放、适宽、整页和实际大小。
  • 连续、单页、双页、封面双页。
  • 全文查找、目录、缩略图、旋转、手型与专注模式。
  • 摘录、高亮、笔记，并可定位回原页。
  • 可视区域懒渲染，适合数百页文件。

Word / Excel / PPT

阅读模式本地解析：Word 保留分页结构，表格支持工作表，演示文稿逐页查看。需要高保真编辑时进入 Office 工作区。

网页

网页资料会提取正文，文档站保留完整目录、章节历史、相邻页预取、40%–240% 整页缩放、摘录与原文定位。

网站限制禁止 iframe 或复杂登录的网站，应使用“原网页”或学习工作台；CodeScope 不绕过网站安全策略。

Markdown 知识库

顶栏“知识库”用于管理和阅读长期积累的 Markdown 文档。CodeScope 使用 VitePress 把文件夹结构自动生成类似 GitBook 的完整文档站。

层级目录

文件夹就是分类，可创建任意层级。

全文搜索

浏览器本地完成中文模糊检索。

大图友好

图片独立保存、按需加载并带缓存。

创建与写作

  1. 打开知识库中心点击顶栏“知识库”，查看页数、图片容量和构建状态。
  2. 创建分类或文档输入如 嵌入式 Linux/设备驱动.md，多级目录会自动建立。
  3. 编辑 Markdown新文档会在阅读模块打开，可使用源码或区块编辑器。
  4. 自动生成保存后 CodeScope 防抖重建站点；状态变为“知识库已更新”后即可阅读。

图片与大容量内容

在知识库中心选择图片分类并导入 PNG、JPG、GIF 或 WebP。图片存放在 readings/知识库/public/images/，界面会复制 Markdown 图片语法。站点启用懒加载，页面不会一次解码全部图片。

阅读与定位

  • 左侧是按文件夹生成的分类树，右侧是当前页面二至四级标题大纲。
  • 顶部搜索支持标题加权、前缀和模糊匹配，所有索引均留在本机。
  • 标题具有稳定锚点，可复制当前链接直接定位；支持上一篇、下一篇和返回顶部。
  • 源文件位于 Vault，站点缓存位于 CodeScope 应用数据目录；缓存损坏时点击“重新生成”即可恢复。
推荐结构知识库/领域/专题/文档.md。分类保持稳定、单篇围绕一个主题，图片按项目或专题归档。

学习工作台

把视频、网页、代码、PDF 和笔记放进可拖拽窗格。常用网址支持搜索、分类、新增与移动。

布局

  • 学习布局：左视频，右侧代码与笔记上下排列。
  • 双栏：视频｜代码或视频｜笔记。
  • 四宫格：视频、资料、代码、笔记。
  • 自由布局：拖动标签和边界任意重组。

B站学习

  1. 打开完整 B站登录、搜索并选择视频。
  2. 载入播放器复制视频地址后放入视频窗格。
  3. 记录时间点在关键位置插入可回跳节点。
  4. 记录视频帧把当前播放器画面加入学习记录。
  5. 同步实践右侧改代码并记录笔记。

Office 与 ONLYOFFICE

DOCX、XLSX 和 PPTX 由 ONLYOFFICE 高保真编辑，文件仍保存在本地 Vault。

启动与关闭

  • “▶ 启动”启动 codescope-onlyoffice，等待“容器 · 健康”。
  • “■ 关闭”停止容器并释放运行内存；编辑时会确认。
  • 关闭只释放运行内存，不删除 Docker 镜像和文档。

XMind 支持双向导图、左右逻辑图、组织结构、目录树、树形表格和时间轴。拖动节点可改变顺序与父级。

工程能力

LaTeX

“＋TeX”生成 main.tex 与 data/figures/fonts；左源码、右 PDF，防抖编译并处理交叉引用。

DeepSeek Harness

CodeScope 自动托管 DSH，默认监听 127.0.0.1:3080。顶栏 Harness 在主区域打开；环境面板可检查、查看日志和重启。

工程面板与 Git

工程面板集中展示任务、测试、调试、编译数据库和健康报告。Git 面板提供 Diff、提交、拉取与推送；危险回退要求短 hash 二次确认。

SSH / VNC

远程面板支持 SSH 终端、远程文件、流式传输和 noVNC。监听 0.0.0.0 时同网段设备可能访问终端和文件接口，只应在可信网络使用。

搜索、引用与 AI

  • 快速打开：搜索代码、阅读、Office 与绘图。
  • 全文搜索：代码、Markdown、LaTeX 与 PDF 摘录，支持正则。
  • 内部链接：复制当前内容链接，建立跨资料引用。
  • 反向链接：查看哪些内容引用当前项目。
  • AI 搜索：结合实时网络资料与当前工程符号。

A. 排序算法与测试

  1. 定位打开“数据结构算法 / C++系列算法 / 排序算法”。
  2. 阅读用大纲定位测试函数。
  3. 运行查看 stdout 和耗时。
  4. 用例添加普通、逆序、重复与负数数组。
  5. 验收全部 Case 通过；改错期望值时显示差异。

B. PDF 深度阅读

  1. 导入长 PDF。
  2. 切换连续、单页和双页。
  3. 搜索关键词并从目录跳转。
  4. 高亮一段原文并写笔记。
  5. 从摘录定位回原页。

C. B站视频学习

  1. 选“左视频＋右代码/笔记”。
  2. 登录 B站并选择视频。
  3. 载入播放器，记录两个时间点。
  4. 插入一张当前视频帧。
  5. 右侧完成一次代码修改并写结论。

D. Office

  1. 启动 ONLYOFFICE 并等待健康。
  2. 打开 DOCX，修改并等待保存。
  3. 重新打开验证写回。
  4. 关闭服务，确认代码和 PDF 仍正常。

E. 架构图

  1. 用 Draw.io 绘制“传感器→控制器→执行器→反馈”。
  2. 运行 XML 校验。
  3. 用 XMind 拆成软件、硬件、通信、测试四支。
  4. 刷新后继续编辑，确认已保存。

F. Harness

  1. 点击 Harness。
  2. 确认状态可用。
  3. 解释当前工程或函数。
  4. 返回代码，用定义、引用和运行验证。

故障排查

现象检查处理
文件全部为空Vault 路径切回 markdown-vault，不要在空目录新建。
布局错位/裁切浏览器缩放与窗口恢复 100%，刷新并重新拖动分割条。
ONLYOFFICE 未连接容器、8088、JWT、回调先启动，再检查连接设置。
PDF 大文件卡缩放与第二栏先适宽/整页，关闭多余栏位。
网页无法加载CSP / iframe改用阅读视图或原网页。
DSH 无法打开环境面板与 3080重启 DSH 并查看日志。
用例输入为空是否读取 stdin使用 cin/scanf/input。
xterm 未加载依赖npm install 后重启并硬刷新。

更新流程

  1. 提交程序改动并备份重要 Vault。
  2. 运行 npm install。
  3. 源资源变化时运行 npm run build:assets。
  4. 运行 npm test 与 npm run test:browser。
  5. 重启并检查环境、Office 与 DSH。
